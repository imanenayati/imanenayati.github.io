Booking notes

  • Set lengths: typically 3 x 45 minutes (customizable).
  • Space needs: comfortable on an 18' x 12' stage; we can scale down if needed.
  • Arrival time: usually 2–3 hours before downbeat for weddings.
  • Noise limits: we can do “controlled volume” rooms without losing energy.
